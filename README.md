### 关于「天和联盟」的如实说明

「天和联盟」是芒果航空品牌演示中的**虚构联盟**，现实世界并不存在该联盟，因此不存在可对接的「现实天和联盟航班」。本接入层对接的是**标准航班数据接口**：任何返回上述格式 JSON 的端点（真实航司 API、GDS/NDC 聚合服务或自建后端）均可接入，接入后即可在搜索结果中看到真实航班数据，页面角标会显示「API 实时」。

## 技术栈

纯静态站点，无需构建：

- `index.html` — 页面骨架 + 底部 Tab
- `css/style.css` — 设计系统（玻璃拟态 / 伪 3D 主视觉 / 响应式 / 三主题）
- `js/i18n.js` — 八国语言字典与本地化（568 键 × 8 语言）
- `js/api.js` — **v1.1** FlightAPI 接入层（真实 fetch / 演示 Mock / 自动降级）
- `js/data.js` — 数据层：36 城机场网络、航班生成引擎（20~28 班/航线，全部有余票）、AI 寻价引擎、`dataAdapter` 双通道（同步演示 + 异步 API）
- `js/games-core.js` — **v1.2** 游戏中心核心：注册表 / 大厅 / 游戏容器 / 管理员外挂系统 / 触控与音效
- `js/games-arcade.js` — **v1.2** 动作街机 5 款：贪吃蛇 / 打砖块 / 弹球对战 / 芒果大作战 / 接芒果

- `js/games-board.js` — **v1.2** 棋类 4 款：五子棋 / 井字棋 / 打地鼠 / 中国象棋（含 AI）
- `js/service.js` — **v1.4** 官方客服 MangoService：悬浮入口 / 聊天面板 / 八语本地知识库 / AI 通道（OpenAI 兼容，默认火山方舟豆包免费模型 `doubao-seed-2-1-pro-260915`）/ 真实连通验证后显示在线 / 失败自动降级

## 云端发布（单文件构建）

发布平台会拦截不带访问凭据的外链 `.js` / 图片请求，因此云端版为**完全自包含的单文件 HTML**（CSS / JS / 图片全部内联，约 1.6MB）：

```bash
node build.js        # 生成 dist/index.html（自动去重内联，图片 base64 内嵌）
node /root/.codebuddy/skills/sites/scripts/publish.js --dir dist --language static
```

- 源码（`index.html` + `css/` + `js/`）保持多文件结构，方便维护与后续开发
- 修改任何源码后，重新执行 `node build.js` 再发布，云端即为最新版
